# 保険診療カルテ 試作（Phase 1）

内科クリニック向けの、2列で作った診察画面の試作です。データはすべて架空のもので、ブラウザ内（localStorage）にだけ保存します。

## 起動

```
npm install
npm run dev   # http://127.0.0.1:5190
```

## 画面

- 左：過去の記載・処方・検査・文書の閲覧（「Do」「引用」「編集」）
- 右：今回の記載（バイタルの構造化入力＋自由記載）とオーダー（院外処方・検査・病名）、紹介状
- 上：受付の待ち一覧と計測（経過時間・操作数）

## ショートカット

| キー | 操作 |
| --- | --- |
| ⌘K | 薬・検査・病名・セット・操作を検索（かな・ローマ字略称可） |
| ⌘D | Do処方 |
| ⌘⇧D | 前回の記載をコピー |
| ⌘L | 紹介状 |
| ⌘Enter | 確定して会計へ（次の待ち患者が自動で開く） |
| ⌘J | 次の患者 |
| ⌘M | 操作計測の結果 |

操作数＝クリック＋ショートカット（文字入力は数えない）。目標は再診60秒・15操作以内。
